# Vouple — Master Project Directives (Lean ₹0 Budget MVP)

## 1. Product Vision & Ground Realities
- **Product:** Vouple — High-Intent Curated Matchmaking for Jabalpur.
- **Budget Constraint:** ₹0 (Zero rupees). Everything must run on 100% Free Tiers (Vercel Free, Supabase Free Tier, Google Fonts, Lucide Icons, zero paid SaaS).
- **Core Strategy:** Start lean, build deep local trust in Jabalpur, validate product-market fit before spending a single rupee.

## 2. Core Value Proposition
- **Anti-Swipe Philosophy:** No endless swiping sludge. Users get **Daily 5 Curated Profiles** delivered every morning.
- **Aesthetic:** Luxury Editorial feel (Playfair Display serif headlines, Plus Jakarta Sans body, Warm ivory/cream background, deep obsidian/charcoal accents, champagne gold highlights).
- **Safety & Trust:** 100% manual review (Mama/Admin verification), Screenshot Shield™ watermark, upfront intent timelines (e.g. "Marriage in 1-2 years", "Serious courtship").

## 3. Technology Stack (₹0 Cost)
- **Framework:** Next.js (App Router) with TypeScript
- **Styling:** Tailwind CSS + Vanilla CSS tokens
- **Animations:** Framer Motion (for smooth mobile card swiping physics)
- **Icons:** Lucide React
- **Hosting:** Vercel Hobby Tier (₹0)
- **Backend/Auth (Stage 2):** Supabase Free Tier (₹0)

## 4. Architectural Rules for Antigravity
1. **Never over-engineer:** Do not add unnecessary cloud microservices or paid APIs.
2. **1 Feature = 1 Focused Step:** Complete and verify each component cleanly.
3. **Mobile-First Luxury Experience:** The app must look like a high-end publication on mobile screens (3:4 aspect ratio portrait cards).
4. **Preserve Integrity:** Never break existing working code when modifying files.
